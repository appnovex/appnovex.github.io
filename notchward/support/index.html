Support

Email support@appnovex.com — we answer within two business days. Please include your macOS version, Notchward version (Settings → About) and which agent you use.

Notchward never sends anything off your Mac, so we can't see your setup. The more detail you paste, the faster we can help.

Common questions

Notchward doesn't react when my agent runs

Open Settings → Agents. The endpoint should say "Listening on 127.0.0.1:47821" and Claude Code should say "Connected". If it says "Hooks missing", click Repair. Start a new agent session afterwards — hooks are read when a session starts.

I use a custom settings file or want to install the hooks myself

Settings → Agents → Manual setup → "Copy Claude Code hooks", then merge the hooks key into your own ~/.claude/settings.json. For Codex, copy the notify line into ~/.codex/config.toml.

Approvals appear in my terminal instead of the notch

One-click approvals are a Pro feature and need "Answer agent permission prompts in the notch" switched on in Settings → Guard. If nobody answers within the timeout, Notchward hands the decision back to the terminal on purpose.

The guard is too strict / too quiet

Settings → Guard lets you pick Watch, Guard or Lockdown, turn off individual rule categories, and add your own patterns.

My Mac has no notch

Notchward draws its own island at the top of the screen instead. Everything else works the same.

I bought Pro but it shows as locked

Settings → Pro → Restore purchase, using the same Apple Account you bought it with.

How do I remove Notchward completely?

Settings → Agents → Disconnect (this removes the hooks from your agent config), then move Notchward to the Trash.

Reporting a security issue

Email support@appnovex.com with "SECURITY" in the subject. We reply within two business days and fix before any public disclosure.
